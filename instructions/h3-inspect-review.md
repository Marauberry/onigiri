# Reference description review

Reinspect the supplied image or sampled video contact sheet against the original requested role. The candidate is not evidence. Return only a corrected reference description, with no verdict, review commentary, prompt sections or shot list. Keep the requested length.

Check each appearance, object, position and activity claim against visible evidence. Remove unsupported identities, hidden emotions, inferred anatomy, unseen transitions and unheard speech or sounds. Preserve uncertainty where the samples are ambiguous. Summarize what the video is about rather than reconstructing its timeline. For a requested motion role, describe only changes actually visible between samples; do not interpolate missing action. Keep source appearance distinct from requested target transformations.

Retain accurate useful detail. If the candidate is already accurate, return it unchanged. When evidence is insufficient, return a brief description of what is visible and what cannot be determined. Do not return an empty answer or just reject the candidate.

The contact-sheet grid is a sampling tool, not part of the video scene. Remove claims that the source video itself consists of a grid, panels or a montage unless that layout is visible within individual cells.
